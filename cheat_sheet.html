M-sys Cheat Sheet
mass_stream
Press(kg/cm2): 절대압력 (0.0 초과, 1atm=1.03323)
Temp(℃): Celsius 온도 (건도 역산 시 빈 칸)
Dryness(-): 0~1 사이 건도 (0:포화액, 1:포화증기)
Flow rate(kg/h): 유량 입력 (m**, v**, s**)
fluid_id: 유체명 또는 조성 (기본값: water)
Remarks
• Input port 없을 때만 수동 입력 유효 (연결 시 pass-through)
• 숫자 또는 m+숫자: 질량유량 (kg/h)
• v+숫자: 운전 체적유량 (m³/h, ρ 연동 변환)
• s+숫자: 표준 체적유량 (Nm³/h, 0℃, 1atm 기준)
• 다성분 건도 역산: Temp를 비우고 Dryness=1.0 입력 시 이슬점 T_dew 자동 도출
사용가능 물질 (Fluid_id)
분류지원 Fluid_id 문자열
물/증기Water, H2O, Steam (IAPWS-IF97)
공기/기체Air, Nitrogen(N2), Oxygen(O2), Argon(Ar), Helium, Hydrogen(H2), CO2, CO
탄화수소Methane(CH4), Ethane(C2H6), Propane(C3H8), Butane(C4H10), Isobutane, Pentane, Hexane, Octane(NC8)

  예) volume:CH4:93.5, C2H6:4.1, N2:0.2
Splitter
Split ratio(0~1): stream2 분배율 / 유량
Remarks
• 0 ~ 1 숫자: Stream 2의 유량 비율 (예: 0.3 → 30% 분기)
• 1 초과 숫자 또는 F:숫자: Stream 2 절대유량 직접 지정 (kg/h)
Pipe
Diameter(mm): 배관 내경, ND호칭경
Length(m): 배관 직관부 길이 (10m 적분)
Equiv.Len: 부속 상당장 [ELBOW:2,GATE:1]
Elevation(m): 배관 고저차 (높이차)
Roughness(mm): 배관 조도, [steel]
Thermal Resist.: 열저항 [R:2.2, T:10]
Remarks
1. Diameter: nd+호칭경 입력 시 Sch.STD 규격 내경 자동 계산 (예: nd300 → 307.04mm)
2. Equiv.Len: Fitting:수량, Fitting:수량 입력 시 L/D 상당장 자동 계산
3. Roughness: 재질 입력 시 조도 자동 매핑
4. Thermal Resist: 빈 칸=완전 단열 (Q_loss=0, 줄-톰슨 팽창) / R:열저항, T:온도 입력 시 외기 방열 계산

pump
Head(m): 펌프 양정 (m), 성능 곡선식
Pump Eff.(%): 펌프 효율 (%), 곡선 수식
Motor Eff.(%): 모터 효율 (%)
Remarks
1. Head / Eff 수식 지원:
y = a*x**2 + b*x + c (x = Flow rate kg/h)
2. 모터 효율 미입력 시:
효성 고효율 모터 표준 사양 자동 적용 (0.75kW 82.5% ~ 160kW 95.0%)
3. NPSHa 계산:
NPSHa = (P_in - P_sat) / (ρ * g) [m]
mixer
Pressure Basis: Mixing 압력 기준 (min / max)
Remarks
• min: 유입 스트림 중 최소 압력 기준 (기본값)
• max: 최대 압력 기준
• 감온수 혼합 시 포화 2상 습증기(0 < x < 1) 에너지 및 질량 수지 완벽 보존
Valve
Outlet_press: 출구 절대압력 (kg/cm².a)
Remarks
• 줄-톰슨 등엔탈피 팽창 (H_out = H_in)
• 공기/과열증기/습증기/과냉액 건도(VF) 엄밀 판정
VLSeperator (기액분리기)
• 2상 플래시 드럼 (별도 입력값 없음)
• 상단 포트(s1_out): 기상 100% 분리 (Q=1.0)
• 하단 포트(s2_out): 액상 100% 분리 (Q=0.0)
• 다성분 VLE 기액 평형 조성 분리 지원
exchanger
Design Basis: 출구 상태 기준 (콤보박스)
Outlet Value: 목표치 (온도 ℃ 또는 건도 VF)
U(W/m²K): 총괄열전달계수 (Default: 280)
Type: counter(대향류) / parallel(병류)
Press Drop: S1 / S2 차압 (kg/cm²)
Efficiency(%): 열교환 효율 (Default: 100%)
Design Basis 옵션
• S1_Outlet_T / S2_Outlet_T: 출구온도 지정
• S1_Outlet_X / S2_Outlet_X: 출구 건도(VF) 지정 (0.0:완전응축, 1.0:완전증발)
• Hot/Cold 스트림 자동 판정 및 LMTD 온도교차 자동 검증
Turbine
outlet_press: 팽창 출구 절대압력 (kg/cm².a)
Adiabatic_eff(%): 단열팽창효율 (%), 곡선식
Remarks
• 스팀 습증기 2상 팽창 및 고온 가스터빈 배가스 팽창 분기 자동 처리
• 터빈 성능곡선 스케일링 수식 지원:
N_FLOW:630, R_FLOW:630, y = a*x**2 + b*x + c
comp (압축기)
Calculation Mode: Adiabatic / Polytropic
Outlet Pressure: 토출 압력 (kg/cm².a)
Calc. Efficiency: 압축 효율 (%)
• ds/dT = Cp/T 초고속 수렴 알고리즘 적용

M-sys Cheat Sheet (Power, Combustion & Control)
Cooling Tower
Wet Bulb(air): 외기 습구온도 [27] ℃
Approach: 접근온도차 [5] ℃ (T_out = WB + App)
Circul.Water flow: 순환수량 (kg/h, 공백시 s1 계승)
Evaporate Rate: 증발 효율 [0.75]
Concentration Factor: 농축 배율 C [5]
수지 계산식
• 증발량: m_evap = (Q_cool * η_evap) / L_v
• 블로다운: m_bd = m_evap / (C - 1)
• 드리프트: m_drift = m_circ * 0.002%
• 보급수량: m_makeup = m_evap + m_bd + m_drift
Power Gen (가스엔진/가스터빈)
Outdoor Temp(℃): 외기온도 (기본: 0℃)
Power Gen(kW): 발전출력 또는 y=f(x) 수식
Aux. Power(kW): 소내 소비전력 (수식 지원)
Fuel Consum(kg/h): 연료 소비량 (수식 지원)
EXH.Flow(kg/h): 배가스 유량 또는 y=f(x) 식
EXH.Press(kg/cm2): 배가스 압력 (kg/cm².a)
EXH.Temp(℃): 배가스 온도 (℃)
EXH.Comp(-): 배가스 조성 (질량기준)
NOx Emission(ppm): 배가스 NOx 농도 (dry base)
O2 Conc.(%): 배가스 산소 농도 (dry base)
• Power Gen 수식: y = a*x**2 + b*x + c (x=Outdoor Temp)
• EXH.Flow 수식: y = a*x**2 + b*x + c (x=Power Gen)
Burner (덕트버너 / 가열기)
(연료 유입): 하단 fuel_in 포트에 스트림 연결
Efficiency(%): 버너 연소 효율 (Default: 100%)
NOx_Emis(ppmv): 버너 생성 NOx 배출농도
O2 Conc.(%): 기준 산소 농도 (통상 15%)
Remarks
• LHV/HHV 및 배가스 생성량(O2 소비/CO2 생성) 자동 해석
• 안전 가드: 연료 스트림에 가연성 가스(CH4 등) 부재 시 또는 산소 부족 시 명확한 한글 경고 자동 출력
SCR_urea / SCR_ammonia
NOx_Emis(ppmv): 보증 배출 농도 (dry base)
O2 Conc.(%): 보증 기준 산소 농도 (통상 15%)
Urea/Ammonia Conc: 요소수(32.5%)/암모니아수 농도
Equiv_Ratio(-): 투입 당량비 (통상 1.05 ~ 1.2)
Remarks
• 실제 운전 O2 농도 기준 환산 NOx 질량 배출량(kg/h) 엄밀 계산식 탑재
evaporator & economizer (HRSG)
• evaporator: 폐열보일러 증발기, 실시간 필요 급수량(required_feed_water_kgph) 및 블로우다운 분기 자동 도출
• economizer: 절탄기, Design 모드(UA 스냅샷) ↔ Simulation 모드(UA_op 운전 스케일링) 지원
control_adjust (DWSIM Adjust)
Manipulated Object: 조작 대상 기기/스트림
Manipulated Property: 조작 변수 (예: Flow rate)
Manipulated Min/Max: 조작 변수 허용 하한 / 상한
Controlled Object: 제어 감시 대상 기기/스트림
Controlled Property: 제어 감시 속성 (예: Temp)
Target Value: 목표치 수치 또는 회귀 수식
Tolerance(%): 수렴 허용 오차 (Default: 0.1%)
Secant 감도 추적 엔진
• 기울기 자동 감지: 가열(양의 기울기) 및 냉각/증발(음의 기울기)을 스스로 판단해 수렴 방향 전진
• 회귀 목표식 지원: y = a*x**2 + b*x + c (x=조작값)
control_set (Set Block)
Deactivate: 일시 비활성화 체크박스
Manipulated Source: Properties / Simulation Result
Set Value: 주입 수식 (예: x, y = a*x + b)
• 스마트 대입: 1e-5 이내 동일 값이면 쓰기를 건너뛰어 하류 캐시 파괴 방지
control_recycle (Recycle)
• 폐루프 순환참조 수렴 블록 (포트 없음, 참조선 연결)
• 1패스 1이완(0.5 Relaxation) 전달로 DWSIM/HYSYS 표준 수렴 속도 보장
properties_table
• DWSIM Master Properties Table 스타일 위젯
• 더블클릭: 한 화면당 표시할 가로 스트림 칼럼 수 분할 다이얼로그 호출
• 표시 물성 7종: Temperature, Pressure, Dryness(-), Density, Enthalpy, Entropy, Flow Rate
• 드래그 이동 및 우측/하단 테두리 자유 리사이즈 지원
Note, Inst & Equip (주석/라벨)
• note: 플로우시트 내 다중행 텍스트 주석 (서식 보존)
• instrument: 특정 mass_stream 물성 실시간 표시
• equip: 단위 장치 계산 결과(전력, 열량 등) PFD 부착 표시
